# Music Only – Пространство для прослушивания музыки

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание проекта
Сайт-визитка для пространства, где можно слушать винил на Hi-Fi оборудовании. 
Проект выполняет роль цифрового гида: знакомит с атмосферой места и правилами посещения.
В дальнейшем будет дополнен разделами фонотеки, афиши лектория и формой бронирования.

## Практическая работа 9
Создана главная страница на Bootstrap-сетке.

Реализовано:
- подключение Bootstrap 5 через CDN;
- кастомная цветовая палитра в стиле «лофт» (`css/custom.css`);
- шапка и адаптивная навигация (`navbar` с бургером);
- hero-блок на сетке (`col-lg-6`);
- блок правил посещения (`col-md-4`);
- сетка карточек с альбомами;
- подвал страницы.
